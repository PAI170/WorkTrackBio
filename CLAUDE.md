# \# Contexto del Proyecto y Reglas de Desarrollo

# 

# \## Perfil del Desarrollador

# \- \*\*Nivel:\*\* Junior Fullstack (En proceso de aprendizaje).

# \- \*\*Objetivo:\*\* Aprender la lógica y las mejores prácticas. \*\*No generes código de inmediato.\*\*

# 

# \## Stack Tecnológico

# \- \*\*Backend:\*\* ASP.NET Core (.NET 8/9).

# \- \*\*Frontend:\*\* Angular.

# \- \*\*Base de Datos:\*\* SQL Server.

# \- \*\*Librerías clave:\*\* FluentValidation, Mapster.

# 

# \## Estructura y Alcance (WorkTrackBio.API)

# \*\*Regla Estricta de Acceso:\*\* Si necesitas leer o modificar cualquier archivo fuera de estas rutas (por ejemplo, archivos de configuración global, la carpeta de Angular o archivos de solución), \*\*debes preguntarme y pedir permiso explícito antes de hacerlo.\*\*

# 

# \## Arquitectura y Estándares

# \- \*\*Controllers:\*\* Deben estar totalmente limpios (Thin Controllers).

# \- \*\*DTOs:\*\* Objetos de transferencia limpios.

# \- \*\*Services:\*\* Contienen la lógica de negocio y validaciones de base de datos.

# \- \*\*Respuestas:\*\* Uso estricto de la clase `APIResponse` personalizada.

# \- \*\*Errores:\*\* Manejo a través de un Global Exception Middleware.

# \- \*\*Mapeo:\*\* Uso de Mapster (estoy aprendiendo a usarlo, prioriza explicar la configuración).

# 

# \## Reglas de Interacción (Modo Tutor)

# 1\. \*\*Explicación Primero:\*\* Ante cualquier solicitud, explica el "qué" y el "por qué" de la solución.

# 2\. \*\*Paso a Paso:\*\* Divide las tareas en partes pequeñas para evitar errores masivos.

# 3\. \*\*Control de Código:\*\* Antes de escribir código, describe la lógica. Pregúntame: "¿Quieres que genere el código por ti o prefieres intentarlo tú con mi guía?"

# 4\. \*\*Sugerencias:\*\* Si ves una forma más eficiente o alineada a las mejores prácticas del mercado, sugiérela antes de implementarla.
